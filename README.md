# Athar

Athar est une PWA privee de coordination du porte-a-porte, pensee d'abord pour
Toulouse puis pour une montee en charge geographique progressive.

## Etat du projet

- Etape 6 terminee : carte applicative MapLibre chargee a la demande, paquet
  PMTiles local, zones, batiments visibles, dessin/edition locale de zones et
  rattachement geographique testes.
- Verdict : GO pour l'etape 7, limitee au prochain lot explicitement demande.
- La fermeture Auth stricte reste une dette acceptee pour usage prive ; Android
  physique est suspendu jusqu'a la beta terrain.
- L'interface visible contient le login, les etats d'acces et la carte
  applicative. Les parcours terrain, la synchronisation bout en bout et le
  pilotage V1 ne sont pas encore construits.
